
# 📊 Projeto de Analytics – Dados em Saúde Pública

## 🎯 Contexto do Projeto
Este repositório reúne análises e estudos aplicados em dados, desenvolvidos ao longo da minha formação em Data Science (USP/ESALQ), com foco na aplicação prática em problemas reais — especialmente no contexto de saúde pública.

A proposta é consolidar conhecimentos técnicos e demonstrar a aplicação de conceitos de análise de dados, estatística e engenharia analítica.

---

## 🎯 Objetivo
Aplicar técnicas de análise de dados para explorar, tratar e gerar insights a partir de bases de dados, apoiando a tomada de decisão baseada em evidências.

---

## 📊 Dados Utilizados
- Bases públicas de dados  
- Dados simulados para estudos analíticos  
- Estruturas de dados utilizadas em exercícios práticos  

---

## 🔧 Ferramentas e Tecnologias
- **Python:** Pandas, NumPy, Scikit-learn  
- **SQL:** consultas, joins e modelagem  
- **Visualização:** Matplotlib, Seaborn  
- **Ambiente:** Jupyter Notebook  
- **Versionamento:** Git e GitHub  
- **Cloud (estudos):** Fundamentos AWS  

---

## 📈 Principais Aplicações
- Análise exploratória de dados (EDA)  
- Limpeza e transformação de dados (ETL)  
- Visualização de dados para geração de insights  
- Modelagem básica e aplicação de conceitos de Machine Learning  
- Estruturação de dados e práticas de Analytics Engineering  

---

## 📂 Estrutura do Repositório

📁 **01-estatistica**  
Análise descritiva, testes de hipóteses e inferência estatística  

📁 **02-bancos-de-dados**  
Consultas SQL, modelagem e manipulação de dados  

📁 **03-visualizacao-de-dados**  
Criação de gráficos, dashboards e storytelling com dados  

📁 **04-cloud-computing**  
Estudos e fundamentos de arquitetura em AWS  

---

## 📌 Evolução do Projeto
Este repositório é contínuo e evolutivo. Novos estudos e análises são adicionados conforme avanço na formação e prática em dados.
